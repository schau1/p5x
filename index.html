P5X Team Builder/Max Damage Calculator

Assumption:

1. If an ability has different percentages per stack, assume max stacks. For example, Makoto can have a max of 4 [Moon Stacks]. The tool will use 4 stacks for calculation (he should always have 4 [Moon Stacks] before S3 if you have his rotation down correctly). This also means that you need to check the unit yourself to see if they can hit the max stack with the team's composition (future improvement to allow stack input).

2. Party members have enough stats to max out any skill that has a max of % stat up to X amount. For example, the description for Leon's Ultima Boosters is "Increase 1 ally's Attack by 19.5% for 2 turns. For each stack of Power of Friendship the target has, increase Attack by 20% of Kamiyama's Attack more (up to 1516.7)," the tool assumes that you hit the max of 1516.7.

3. For any ability that has no max, assume max stat from other Skill. For example, 5 stacks of Bloom increases ATK based on 8% own CRIT DMG over 100%. This ability has no max. The calculator will assume CRIT DMG 338% at LVL10 and 418% at LVL 13 and so on.

4. If something has a chance to happen, assume it will always happen if you pick that option. If something randomly gives an effect, assume the first effect (future improvement).

The final calculation may also be off due to the following factors: Bonus from Thieves' Den not accounted for, rounding errors, more stats from your support than expected (#3 assumption as stated above), unclear translation (increased by x% - interpreted as multiplication instead of addition), and of course bugs. Use this as something to compare builds with the same baseline instead of as an absolute number calculator. For example, use it to compare Wonder's knives and see if it's worth getting one reforged with your limited currency or use it to see which card set is better. Just play the game if the exact number is what you need.

This tool was created out of love for the Persona 3 Protagonist (Makoto Yuki). As a result, it only contains useful characters already released + Makoto and his supports and only calculates damage for DPS that scales with ATK (Assassins and Sweepers but not Fox). The Makoto's #2 biggest fan is still working on adding the rest of the characters and any new one, but they are unpaid and not a web developer (ugly UI proved it), so it may take some time.
